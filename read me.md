# ❤️ Love Calculator

A fun and interactive Love Calculator built using HTML, CSS, and JavaScript.

This project allows two people to enter their names and discover their playful love compatibility percentage along with personalized messages. Users can also customize the website's background colour according to their preferences.

## ✨ Features

- Enter two people's names.
- Calculate love compatibility percentage.
- Display personalized love messages.
- Customize background colour according to user choice.
- Interactive and attractive user interface.
- Responsive design for different screen sizes.
- Calculate Again option.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling, animations and responsive design.
- JavaScript – Compatibility calculation, DOM manipulation, event handling and background colour customization.

## 🚀 How to Use

1. Open the Love Calculator website.
2. Enter the first person's name.
3. Enter the second person's name.
4. Click the Calculate button.
5. View your love compatibility result.
6. Change the background colour according to your choice.
7. Calculate again with different names.
